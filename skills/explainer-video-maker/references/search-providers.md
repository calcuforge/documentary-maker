# Search Providers — Reference Guide

> **When to load:** Step 3 (topic research), or when adding a custom provider.

## Architecture

Search providers live in `scripts/search_provider/` under the skill directory. Each
provider is a standalone Python script that outputs a Markdown file with
structured research results.

Providers are **extensible**: the agent can create custom providers for
specialized data sources (e.g., e-commerce price APIs, government databases).

---

## Built-in Providers

### search_provider/search.py — Browser Search

Uses Playwright (Chromium) to visit search engines and encyclopedias.

```bash
python3 "${SKILL_DIR}/scripts/search_provider/search.py" \
  --query "法航447空难" \
  --output /abs/path/search_results/result1.md \
  [--sources baidu,baike,bing] \
  [--max-pages 5] \
  [--visit-top 5] \
  [--timeout 30000]
```

| Option | Default | Description |
|--------|---------|-------------|
| `--query` | (required) | Search query |
| `--output` | (required) | Output .md file (absolute path) |
| `--sources` | auto (locale) | Comma-separated: `baidu`, `bing`, `sogou`, `google`, `baike`, `wikipedia` |
| `--max-pages` | 5 | Max results per search engine |
| `--visit-top` | 5 | Number of top results to visit for full content |
| `--timeout` | 30000 | Page load timeout (ms) |

**Locale auto-detection (default sources):** detected by **network reachability**
(Baidu reachable + Google blocked ⇒ China), falling back to system locale/timezone.
- China network → `baidu` + `baike` + `bing` (uses cn.bing.com). Google/Wikipedia
  are **unreachable** in domestic China — `search.py` drops them even if explicitly
  passed via `--sources`.
- International → `google` + `wikipedia` + `bing`

**Baike search strategy** (3 fallback levels):
1. Baidu site-restricted search (`site:baike.baidu.com {query}`)
2. Baike's own search page (`baike.baidu.com/search?word=`)
3. Direct URL access (`baike.baidu.com/item/{query}`)

### search_provider/search_rss.py — RSS Feed Search

Fetches an RSS/Atom feed via `curl`, selects articles, visits them via
Playwright, and extracts content.

```bash
python3 "${SKILL_DIR}/scripts/search_provider/search_rss.py" \
  --feed-url "https://rsshub.app/36kr/newsflashes" \
  --output /abs/path/search_results/result2.md \
  [--max-articles 5] \
  [--keywords "GPU,pricing"] \
  [--timeout 30000]
```

| Option | Default | Description |
|--------|---------|-------------|
| `--feed-url` | (required) | RSS/Atom feed URL |
| `--output` | (required) | Output .md file (absolute path) |
| `--max-articles` | 5 | Max articles to fetch and visit |
| `--keywords` | (none) | Comma-separated filter keywords |
| `--timeout` | 30000 | Page load timeout (ms) |

## RSS Source Discovery

### tool/search_rss_discovery.py — Find RSS Feeds

Searches for RSS feeds matching a topic. Useful when `rss_source_list` in
project_config.yaml has no suitable feeds.

```bash
python3 "${SKILL_DIR}/scripts/tool/search_rss_discovery.py" \
  --query "GPU pricing news" \
  [--output /abs/path/rss_sources.json] \
  [--max-results 10]
```

Returns JSON array: `[{"url": "...", "title": "...", "description": "..."}]`

**After discovery:** Cache useful feeds into `project_config.yaml`:
```yaml
rss_source_list:
  - url: https://rsshub.app/36kr/newsflashes
    description: "36Kr tech news (Chinese)"
  - url: https://feeds.arstechnica.com/arstechnica/index
    description: "Ars Technica tech news"
```

## Custom Providers

When built-in providers don't meet the need (e.g., structured e-commerce data,
API-based sources), the agent creates a custom provider.

**Requirements for custom providers:**

1. Place the script in `scripts/search_provider/` directory
2. Accept `--output` parameter (absolute path to .md output)
3. Output structured Markdown with source attribution
4. Use Playwright for any website access (never raw requests for HTML pages)
5. Use `curl` only for APIs/RSS that return structured data
6. Handle network locale (China vs. international sites)
7. Print a summary line on success

**Example use case — daily price report:**
```bash
python3 "${SKILL_DIR}/scripts/search_provider/search_ecommerce.py" \
  --product "RTX 5090" \
  --platforms "jd,taobao" \
  --output /abs/path/search_results/prices.md
```

## Output Format

All providers output Markdown with this structure:

```markdown
# Search Results: {query}

*Generated by {provider_name}*

## Result 1: {title}
- Source: {source_type}
- URL: {url}

{content}

---

## Result 2: {title}
...
```

## Provider Selection Guide

| Video Type | Primary Provider | Secondary |
|-----------|-----------------|-----------|
| Documentary (history, science) | search.py (baike/wikipedia) | agent web_search |
| Knowledge sharing / Tutorial | search.py + agent web_search | — |
| News / Daily report | search_rss.py | search.py |
| Product introduction | search.py | custom (official specs) |
| Price / Data report | custom provider | search_rss.py |
| Hardware reviews | search.py | search_rss.py (tech feeds) |
